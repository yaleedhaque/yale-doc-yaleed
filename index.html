What it actually is

One HTML file containing an encrypted JSON payload, and the editor that reads it. There is nothing else to install, so there is nothing else that can break.

Writing

The parts that make it feel like a real editor rather than a textarea.

1

Markdown shortcuts

Type # , - , 1. , > , [] or ``` to get a heading, list, quote, to-do or code block. **bold**, *italic*, ~~strike~~ and `code` work as you type.

2

Insert menu

Type / anywhere for headings, lists, tables, images, links, dividers and page breaks. Filters as you type, driven by the arrow keys.

3

Tables that behave

A floating bar appears when your cursor enters a table: add or remove rows and columns, toggle the header row, delete the table. Tab moves between cells.

4

To-do lists

Real checkboxes whose state lives in the document, so your list is still ticked when you reopen the file on another device.

5

Images, embedded

Button, drag-and-drop or paste. Resized and re-encoded in your browser and stored inside the ciphertext. Nothing is uploaded, ever.

6

Find & replace

Highlighting through the CSS Custom Highlight API where it exists, with a <mark> fallback — and it never damages your text.

Keeping and recovering work

7

Version history

Every save stores the previous version as an encrypted snapshot inside the file. Undo survives closing the tab, reopening, and emailing it to yourself.

8

Attachments

Drop in a PDF or a zip. It is encrypted into the document and written back out on save. A size meter keeps the file honest.

9

Save in place

On Chrome and Edge, Ctrl+S overwrites the same file instead of filling your Downloads with document (3).html.

10

Never lose text

An unsaved-changes guard on tab close, a global error boundary, and a save failure that reports itself and keeps your document exactly where it was.

Reading and looking

11

Measured page guides

The status bar reports the real page count and the margins show where the printed page actually breaks — A4 or US Letter.

12

Three themes, real dark mode

Paper, ink and sepia, each with a declared color-scheme so scrollbars and form controls match. Verified for contrast, not eyeballed.

13

Focus and reading modes

Plus zoom, a live outline built from your headings, word and reading-time counts, and four document fonts.

Security

The document's Content-Security-Policy is default-src 'none', and its only script is allowed by a nonce baked in at build time. So a pasted <script> cannot execute even if it somehow survived sanitising.

default-src 'none';
script-src 'nonce-<128-bit random, baked at build>';
style-src  'unsafe-inline';
img-src    data: blob:;
connect-src 'none';
base-uri   'none';  form-action 'none';  frame-src 'none';  object-src 'none';

The full threat model — including what is deliberately not claimed — is in docs/SECURITY.md.

Verified, not asserted
